  • 사용자 작성 정보: 프로젝트 이름·색상, 할 일 제목·메모·마감 날짜와 시간·완료 상태· 배치 좌표 및 연결 관계.
  • 선택적 Google 연결 정보: Google 계정 식별자·이메일, 캘린더 목록의 이름·식별자·접근 권한, 선택한 캘린더 식별자·이름, 인증 갱신 토큰.
  • 동기화 정보: 선택한 캘린더의 일정 식별자·제목·설명·시작 및 종료 시각 등 처리에 필요한 일정 데이터, 할 일과 일정 사이의 연결 정보, 변경 비교용 데이터 및 마지막 동기화 시각.

2. 이용 목적과 Google 권한

회원 정보는 로그인과 사용자별 데이터 구분에, 작성한 정보는 할 일 관리와 기기 간 이용에 사용합니다. Google 연결은 선택 사항이며, 캘린더 목록 조회와 사용자가 선택한 캘린더의 일정 생성·조회·수정·삭제를 위해 권한을 요청합니다.

현재 연동은 사용자가 동기화 버튼을 누를 때 실행합니다. Google API 권한에는 캘린더 일정 접근이 포함되지만, 서비스의 동기화 처리는 선택한 캘린더를 대상으로 합니다. Google에서 가져온 새 일정은 Tasknest의 Google Calendar 프로젝트에 저장합니다.

Google API에서 받은 데이터는 설명된 계정 연결·동기화 기능에 한정해 사용하며, 광고 타기팅·판매 또는 범용 AI/기계학습 모델 학습에 사용하지 않습니다. Google 데이터의 이용과 다른 서비스로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수하도록 운영합니다.

3. 저장 위치와 접근

웹사이트 호스팅은 Vercel을, 계정·데이터 저장과 서버 함수는 Supabase를 사용합니다. Google Calendar 연동 시 필요한 데이터는 Google과 Supabase 사이에서 처리됩니다. 서비스 제공 과정에서 해당 제공업체의 해외 인프라에서 데이터가 처리될 수 있습니다.

Google 갱신 토큰은 브라우저에 제공하지 않고 서버용 데이터베이스에 보관합니다. 일반 계정은 자신의 서비스 데이터에 접근하도록 제한합니다. 다만 프로젝트 관리자 권한을 가진 운영자는 데이터베이스의 사용자 데이터와 연동 정보에 기술적으로 접근할 수 있습니다. 운영자는 서비스 제공, 사용자 요청 처리, 장애 대응 및 보안 점검에 필요한 범위에서만 접근합니다.

개인정보를 판매하지 않으며, 서비스 제공업체를 통한 처리, 사용자가 요청한 동기화, 법령상 요구 등 필요한 경우 외에 임의로 제3자에게 제공하지 않습니다. 선택한 Google 캘린더의 공유 설정에 따라 내보낸 일정을 다른 Google 사용자도 볼 수 있으므로 연결 전에 공유 범위를 확인해 주세요.

계정·프로젝트·할 일은 서비스 이용 중 보관되며, 사용자가 삭제하거나 계정 삭제 요청이 처리될 때 삭제합니다. 삭제된 할 일과 연결된 동기화 정보는 다음 동기화 시 정리될 수 있습니다.
